# Dictionary data — provenance and scope

The apps built from this code (Interslove `com.radoslove.interslavic`, Mellomskandinavisk
`com.radoslove.interscandinavian`) bundle one wordlist per keyboard language in
`app/src/main/assets/`. Each is a list of word **forms** with frequencies — `word=…,f=…`
lines. **No definitions, translations, glosses or other dictionary content.** A language's
list is loaded only when that language is first used.

| Asset | Language | Made from | License of the list |
|---|---|---|---|
| `main_isv.combined` | Interslavic | forms machine-generated by an inflection engine from a lemma list compiled from various Interslavic lexical resources; frequencies from a text corpus | see below |
| `main_isc.combined` | Interscandinavian (Norwegian profile) | [FrequencyWords](https://github.com/hermitdave/FrequencyWords) `no_50k` (OpenSubtitles) + the [Interscandinavian](https://github.com/radoslove/Interscandinavian) concept forms, Bokmålsordboka-filtered; built in [keyboard-interscandinavian](https://github.com/radoslove/keyboard-interscandinavian) (`dictionary/build_combined.py`) | CC BY-SA 4.0 |
| `main_nb.combined` | Norwegian bokmål | FrequencyWords `no_50k`, Bokmålsordboka-filtered (`tools/build_freq_wordlist.py`) | CC BY-SA 4.0 |
| `main_en.combined` | English | FrequencyWords `en_50k` (`tools/build_freq_wordlist.py`) | CC BY-SA 4.0 |
| `main_pl.combined` | Polish | FrequencyWords `pl_full` + [PoliMorf](https://zil.ipipan.waw.pl/PoliMorf) 0.6.7 (BSD 2-Clause) (`tools/build_pl_wordlist.py`), plus the past-personal and conditional forms PoliMorf cannot hold because their endings are agglutinants (`tools/build_pl_aglutynanty.py`, +136 577 forms, 2026-11-04), plus first names and surnames from the PESEL register ([dane.gov.pl](https://dane.gov.pl) datasets 1667 and 1681, `tools/build_pl_names.py`) — ⚠ reuse terms of the PESEL lists still to be confirmed before a release | CC BY-SA 4.0 |
| `main_cs.combined` | Czech | FrequencyWords `cs_50k` + [hunspell cs_CZ](https://github.com/LibreOffice/dictionaries/tree/master/cs_CZ) (GPL/LGPL/MPL), read through [spylls](https://github.com/zverok/spylls) as a lookup only (`tools/build_cs_wordlist.py`) | CC BY-SA 4.0 |
