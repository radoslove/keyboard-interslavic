## Scope: this license vs. the bundled wordlist data

The MIT license above covers the model **source code and packaging** authored
for this project (the model definition, build/packaging files, and this
repository's own code).

It does **not** purport to license the bundled **wordlist data**. That data is a
list of Interslavic word **forms** with corpus frequencies only — no
definitions, translations, or other dictionary content. The forms are
machine-generated by an inflection engine from a lemma list compiled from
various Interslavic lexical resources; the frequencies are
derived from a text corpus. **No ownership of, or license over, the underlying
lexical data is claimed here.** It is included solely to support this free,
non-commercial tool for the Interslavic language. Individual word spellings and
frequency counts are facts, not copyrightable expression.
