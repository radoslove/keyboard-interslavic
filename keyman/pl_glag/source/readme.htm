Glagolitic (Polish)

Type Polish as usual; the keyboard writes Glagolitic. ą ć ę ł ń ó ś ż ź = AltGr + a c e l n o s z x.

ⰳⱁ́ⱃⰰ ⱞⱁ́ⰹ ⱁ́ⱄⱞⱏⰹ · ⱎⱍⱔⱄⱐⱌⰻⰵ · ⱃⱐⰵⰽⰰ · ⱈⰾⰵⰱ · ⰷⰻⰵⱀⱐ

Q: ja (Ⱑ). X: dzelo (Ⰷ). ch joins by itself (Ⱈ), h stays Ⱒ.

AltGr+D: a d that does not join the next z (od|zyskać). AltGr+V: soft yer, AltGr+Y: hard yer, AltGr+Q: jo (Ⱖ).

AltGr+T or AltGr+`: titlo, typed after the letter.

Font: Noto Sans Glagolitic or Segoe UI Historic.
