Glagolitic (Polish) keyboard
==============

Polish in Glagolitic (pl-Glag). Generated by `build_glag_desktop.py` from the phone's
table (`Script.kt` POLISH_GLAG); do not edit `source/` by hand.

Build: `python -X utf8 build_glag_desktop.py && kmc build keyman/pl_glag/pl_glag.kpj`

Supported Platforms
-------------------
 * Windows
 * macOS
 * Linux
