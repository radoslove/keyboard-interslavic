# iOS app — stage 2

The Keyman package (`keyman/isv_latin.kmp`) is stage 1 and works today. This is
the replacement track, and it exists for two reasons that are worth stating
plainly, because neither is "swipe":

1. **No Full Access.** Since iOS 16 the Keyman system keyboard renders blank
   until the user grants Full Access — a permission that, by design, lets a
   keyboard transmit what you type. Our own extension declares
   `RequestsOpenAccess: false`, so it *cannot* send anything anywhere. For a
   project whose pitch is "no registration, no account, no e-mail", that is the
   honest end of the story rather than an asterisk.
2. **No prerequisite.** One install instead of "first install Keyman, then find
   Install From File".

Swipe is the third reason and the expensive one — see below.

## State

Test builds run daily on an iPhone 13 since 2026-10-07 (`0.1.x` → `0.2.1`); not in
the App Store or TestFlight yet.

| Piece | State |
|---|---|
| Xcode project | generated by XcodeGen from `project.yml` |
| Container app | setup + privacy screen, SwiftUI |
| Keyboards | **two extensions in one app**: `isv` (Interslavic) and `pl` (Polish), same code; the language comes from `KeyboardLanguage` in each extension's Info.plist |
| Swipe | own decoder (`SwipeDecoder.swift`) over `Resources/<lang>_swipe.bin`; learns the user's touch offset |
| Suggestion bar | swipe candidates, completions while tapping, `＋ word` saves to the phone |
| Layout | letters, `123` + `#+=` pages as on iOS, `, . ?` on the letter layer, punctuation and other languages' letters on longpress |
| Debug builds | log gestures and shift decisions to `Documents/gestures.jsonl` in the extension container |

## Build

```sh
brew install xcodegen      # once
cd ios && xcodegen generate
open InterslavicKeyboard.xcodeproj
```

Rebuild the wordlists first if they changed: `python3 build_swipe_dictionary.py`
(isv) and `python3 build_swipe_dictionary.py pl` (see `dictionary/sources_pl/README.md`).

Requires **Xcode** (~10 GB). Running on your own device needs only a free Apple
ID; the profile expires after 7 days and needs re-signing. Shipping to other
people needs the **Apple Developer Program, $99/year**, plus App Store review.

The `.xcodeproj` is generated and git-ignored on purpose — a `pbxproj` cannot be
reviewed in a diff and conflicts on every merge. `project.yml` is the source of
truth.

## Layout parity

`Keyboard/Layout.swift` restates the table from `docs/ms-latin-table.md` — the
same four letters on the same base keys as Windows AltGr, macOS Option, the
Android swipe and the Keyman longpress. If that table ever changes, this file is
a fifth place that has to change with it. The Polish keyboard has its own table
in the same file (`Layout.accents`), and `build_swipe_dictionary.py pl` folds the
same letters.
